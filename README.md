# TowCalcify
Know your tow, before you go. Vehicle towing capacity, payload & safety calculators using certified OEM specs and SAE J2807 ratings.

🔗 Live website: https://towcalcify.tech

## What it does
- Vehicle towing capacity calculators for 17 models
- Payload and tongue weight calculations
- Safe / Approaching Limit / Overloaded safety meter
- Towing 101 guides
